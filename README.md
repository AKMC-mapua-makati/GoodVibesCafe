# GoodVibesCafe
Inventory Management and POS System for cafes with stock tracking and sales reporting.

## Overview
A simple Inventory Management and POS System designed for cafés to manage products, track inventory, and process transactions efficiently.

## Features
- POS transaction processing  
- Inventory tracking  
- Product and recipe management  
- Sales and inventory reports  

## Tech Stack
- Python  
- SQL Database
- Php

## Usage
1. Run the application  
2. Add products and ingredients  
3. Process transactions  
4. View reports
